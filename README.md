# Deskripsi Program
Program ini merupakan program sederhana untuk mengelola data grup NCT beserta member dan unitnya. Program dibuat menggunakan konsep Object Oriented Programming (OOP) dengan menggunakan beberapa class yang saling berhubungan. Tema NCT dipilih karena NCT memiliki beberapa unit dan susunan member yang dapat berbeda-beda.
Program ini dibuat menggunakan:
- C++
- Python
- Java (opsional/bonus)

Pada program ini digunakan 5 class yaitu:
1. Member
2. Vocalist
3. Rapper
4. Unit
5. NCT
